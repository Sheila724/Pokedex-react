# Pokédex React
 Uma aplicação web desenvolvida com React e TypeScript que consome a PokéAPI para exibir informações sobre os Pokémon

# 🧰 Tecnologias Utilizadas
### React​
### GitHub
### TypeScript​
### PokéAPI​
### Axios​
### React Router​
### Styled Components​
### Expo Go

## 📦 Instalação
### Clone o repositório:

``git clone https://github.com/Sheila724/Pokedex-react.git``

### Acesse o diretório do projeto:
``cd Pokedex-react``

### Instale as dependências:​
``npm install
ou
yarn install``

### Inicie a aplicação:
``npx expo start``
